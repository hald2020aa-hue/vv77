# Storage Phase 2F — تبويب التخزين

المرجع: `feature/storage-phase2` عند `68475a1d136fda123d60622c5c13b0af39568af2` (بناء GitHub Actions رقم 45838947220 ناجح قبل هذه الرقعة).

## التنفيذ

- `nav_storage` في القوائم السفلية والجانبية لكل من `main` و`dev`، مع المحافظة على ترتيب الوجهات القديمة. ست وجهات سفلية في dev وخمس في standard (الإعدادات في standard تظل متاحة بآليتها السابقة).
- تبويب حقيقي يستعمل `StorageController` ذاته، كما تبقى مداخل الرئيسية والإعدادات السابقة متاحة. لا يوجد مدير تنزيلات ثانٍ.
- استعادة اختيار التبويب بعد إعادة إنشاء Activity، وإبقاء تفضيل بدء التطبيق السابق عند مغادرة التخزين.
- أيقونة تخزين vector غير اتجاهية، ووضع الأيقونة أعلى النص، وإيقاف تغيير العرض الأفقي عند الاختيار، والسماح بسطرين للعناوين. مكتبة Material Components 1.14.0 المثبتة بالفعل تدعم 6 عناصر في BottomNavigationView (راجع مصدر الإصدار في `lib/java/com/google/android/material/bottomnavigation/BottomNavigationView.java`). لا تبديل للمكتبة أو تجاوز لحدها الداخلي.
- عند فتح التخزين كجذر على الشاشة الكبيرة، يعامل كجذر في حساب هامش شريط التنقل الجانبي؛ وعند فتحه من الإعدادات يبقى شاشة فرعية. حساب الحشو يستخدم الشريط المرئي أو مساحة النظام الفعلية.
- تحديث callback الرجوع عندما يتغير وضع عرض العمل أو التحديد، ومنع التنقل بين التبويبات أثناء الحذف أو حفظ التصنيف. يبقى سلوك الانتقالات الحالي بلا تعديل.
- فاحص `qa/storage/check_navigation.py` يضاف إلى quality gate؛ لا إزالة لأي فحص سابق.
- لا تعديل لقاعدة البيانات أو الاسم أو applicationId أو منطق المصادر/الشبكة/التنزيلات والحذف.

## التحقق

نجحت 23 نقطة تحقق ثابتة للتنقل، وفحوص التخزين السابقة، وفحص الموارد (0 أخطاء). تم فحص تطابق ملفات الرقعة الأصلية مع بصمات GitHub للالتزام المرجعي. فحص التطبيق الفعلي يحتاج GitHub Actions وAndroid. النسخة المحلية المعاد تجميعها من الرقع السابقة لم تكن مطابقة لجميع ملفات إصلاح المرحلة 1، ولذلك لا يجوز اعتبار فحصها المحلي بديلًا عن بناء الفرع الحقيقي.

## اختبار الهاتف المطلوب

- ظهور زر التخزين مع الأقسام السابقة على الشاشة الخارجية والداخلية، بالعربية RTL والإنجليزية، وبخط كبير.
- فتحه من الشريط السفلي والجانبي، ثم من الإعدادات. فتح عمل والرجوع إلى القائمة، وإلغاء التحديد بالرجوع، ثم التبديل إلى المكتبة والتصفح.
- تدوير الشاشة/فتح الجهاز القابل للطي والتأكد من اختيار التبويب الصحيح وعدم وجود تداخل مع الشريط أو حواف النظام.
- التحقق من عدم التنقل أثناء عملية الحذف، وتجربة الحذف على تنزيلات قابلة للاسترجاع، والتأكد من سلامة المكتبة والسجل.
- تجربة القراءة دون إنترنت، والتحديث عند الاتصال، والترقية ببيانات حقيقية من نسخة سابقة بعد أخذ نسخة احتياطية.

لم تُختبر هذه الحالات على هاتف أو محاكي. لم يُرفع التعديل ولم يُبن APK لهذا الالتزام بعد.
